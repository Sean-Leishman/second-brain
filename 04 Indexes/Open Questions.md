## How to read this

Format per entry:

```
## [YYYY-MM-DD] <question, one line>
- **Gap:** missing-source | missing-base-note | unresolved-contradiction | out-of-scope
- **Suggested action:** <ingest X, write Base Note on Y, lint contradiction between A and B>
- **Related:** [[links]]
- **Status:** open | resolved (→ [[resolution note]])
```

Resolved entries stay — the log is append-only. Strikethrough or update the `Status` line.
