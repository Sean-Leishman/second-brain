# Second Brain - Obsidian Vault Structure

My Obsidian vault templates and structure.

## Folder Structure
```
00 Bases/           <- Entry points with Obsidian Bases
01 Fleeting Notes/  <- Quick capture, inbox
02 Sources/         <- Papers, Books, Lectures, Articles
03 Tags/            <- Topic hubs
04 Indexes/         <- Course/subject indexes
05 Base Notes/      <- Permanent notes
06 Daily Notes/     <- Daily journal
07 Projects/        <- Active projects
08 Trackers/        <- Reading/watch lists
99 Archive/         <- Old/completed items
99 Templates/       <- Note templates
```

## Templates
- `Base.md` - General notes
- `Paper.md` - Academic papers
- `Books.md` - Book notes
- `Movies.md` - Movie notes
- `Project.md` - Project tracking

## Usage
1. Clone/copy this structure to start a new vault
2. Configure Templater plugin to use `99 Templates/`
3. Copy `.obsidian/` settings as needed
